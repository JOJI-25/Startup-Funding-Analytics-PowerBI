# 📊 Startup Funding Analytics - Power BI Dashboard

Interactive Power BI dashboard analyzing startup funding trends, investment patterns, and key business insights.

## 🎯 Project Overview

This project features a comprehensive Power BI dashboard designed to analyze and visualize startup funding data. It provides interactive visualizations and insights into investment patterns, funding trends, and key metrics in the startup ecosystem.

## ✨ Key Features

- **Interactive Visualizations**: Dynamic charts and graphs for data exploration
- **Funding Trend Analysis**: Track investment patterns over time
- **Investment Insights**: Understand key metrics and business patterns
- **Cleaned Data**: Pre-processed dataset for accurate analysis
- **User-Friendly Dashboard**: Intuitive interface for data exploration

## 📥 Getting Started

### Prerequisites

- Microsoft Power BI Desktop (latest version recommended)
- Microsoft Excel or compatible spreadsheet software
- Basic knowledge of Power BI for customization

### Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/JOJI-25/Startup-Funding-Analytics-PowerBI.git
   cd Startup-Funding-Analytics-PowerBI
   ```

2. **Open the Dashboard**
   - Open `start_up.pbix` with Microsoft Power BI Desktop
   - The dashboard will automatically load the data from `cleaned_startup_funding.xlsx`

3. **Explore the Data**
   - Use interactive filters and visualizations
   - Drill down into specific funding categories or time periods
   - Export insights and reports as needed

## 📊 Data Source

- **File**: `cleaned_startup_funding.xlsx`
- **Size**: 271 KB
- **Format**: Excel spreadsheet
- **Status**: Pre-cleaned and processed for analysis

The dataset contains startup funding information including:
- Investment amounts
- Funding rounds
- Company information
- Investment patterns and trends

## 📈 Dashboard Insights

The Power BI dashboard provides analysis of:

- **Funding Trends**: Historical investment patterns and growth trajectories
- **Investment Distribution**: Allocation of capital across sectors/regions
- **Key Metrics**: Average funding amounts, success rates, and other KPIs
- **Pattern Recognition**: Identifying trends in startup funding behaviors

## 📋 How to Use

1. **Open the PBIX file** in Power BI Desktop
2. **Interact with visualizations**:
   - Click on charts to filter data
   - Use slicers to narrow down analysis
   - Hover over data points for detailed information
3. **Export Reports**: Generate custom reports and export data
4. **Customize**: Modify visualizations, add new metrics, or extend the analysis

## 🔄 Data Refresh

To update the dashboard with new data:

1. Update the `cleaned_startup_funding.xlsx` file with new data
2. Open `start_up.pbix` in Power BI Desktop
3. Refresh the data source connection if needed
4. Publish to Power BI Service for online access (optional)
